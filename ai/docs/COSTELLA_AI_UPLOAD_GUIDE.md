# Guía de carga — conocimiento de Costella

## Documento principal

Sube `costella-knowledge.md` como documento de referencia del asistente.

## FAQ estructurada

`costella-faq.json` contiene las preguntas frecuentes en formato estructurado para futuras integraciones con RAG, D1 o un CMS.

## Importante

La base fue redactada a partir de la información comercial proporcionada para Costella. El asistente debe tratar precios, fechas de entrega, financiamiento y disponibilidad como información sujeta a confirmación cuando el usuario solicite condiciones actuales o personalizadas.

No incluir en la base pública el documento de modelos de casas como catálogo de Costella.
