# Costella · Landing v1

Prototipo visual de landing single-page para Costella Telchac Residencial.

## Fuente visual
Los renders/visuales utilizados en esta versión son páginas renderizadas del Brochure_Español_Horizontal.pdf proporcionado por el cliente. Modelo_Casas.pdf no se utiliza en la landing.

## Archivos
- `index.html` — estructura completa.
- `css/style.css` — identidad visual, responsive y componentes.
- `js/config.js` — variables que se conectarán al final.
- `js/main.js` — navegación, modal de leads, animaciones y hooks de tracking.
- `assets/brochure/` — visuales derivados del brochure para esta maqueta.

## Pendiente de integración
- URL real de Google Calendar/Meet del asesor.
- WhatsApp del asesor/equipo.
- Endpoint de leads (Apps Script + Google Sheets, si se mantiene esta opción).
- Meta Pixel ID y eventos finales.
- CMS/admin para editar textos e imágenes.
- Sustituir los renders de página completa por los archivos finales de cada render, si el cliente los proporciona por separado.
